# Notion Clone

Notion風のメモ・ドキュメント管理アプリを模したWebアプリです。  
フロントエンドとバックエンドを分離し、CRUDを中心とした基本機能を実装しています。

実務を意識した構成で、React / Redux / Node.js / Express / MongoDB を用いて開発しました。

---

## 🔥 主な機能

- ドキュメントの作成 / 編集 / 削除（CRUD）
- メモ・ドキュメント管理
- Reduxによる状態管理
- REST APIによるフロント・バックエンド連携
- MongoDBを用いたデータ永続化

※ UI / UX は Notion を参考にしています（完全再現ではありません）
